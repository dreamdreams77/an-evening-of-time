# Characters & Items — An Evening of Time

30 items across 17 characters. This file is a plain-text reference for everything `index.html` collects; the game itself is the source of truth if the two ever drift.

Nine characters — marked **Fairyland** below — are guests from the companion project [FairyQueenTales](https://github.com/dreamdreams77/FairyQueenTales). They don't appear in the world until you've collected the Fairy Sparkle from The Fairy; after that they're scattered through the scene like everyone else.
